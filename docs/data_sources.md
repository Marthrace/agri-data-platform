\## Notes

\- Prices cover the years 2006 to 2023, so the project uses 2020 to Jul 2023.

\- FAOSTAT is annual. Prices and production overlap for 2020 to 2023.

\- WFP has no plain "Tomatoes" commodity; the project uses "Tomatoes (local)".
